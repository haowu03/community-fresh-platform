# 社区便民生鲜配送平台 — 业务流程梳理

> 订单主状态机（支持配送到家与社区自提双履约）：
> `1 待付款 → 2 待接单 → 3 备货中/待配送 → 4 配送中/待自提 → 5 已完成`，支干线 `6 已取消`。
> 自提单：3 备货完成 → 4 待自提（生成自提码）→ 核销 → 5 已完成。

---

## 1. 普通下单流程（配送到家）

```mermaid
flowchart TD
    A[用户浏览商品/搜索] --> B[加入购物车<br/>按份或按重量]
    B --> C[选择收货地址]
    C --> D[提交订单 deliveryType=配送]
    D --> E{校验: 地址/库存/批次}
    E -- 失败 --> F[返回错误提示]
    E -- 成功 --> G[创建订单+明细<br/>扣减批次库存/乐观锁]
    G --> H[清空购物车]
    H --> I[模拟支付]
    I --> J[订单=待接单<br/>管理端接单→派送→完成]
```

## 2. 自提流程（社区自提点）

```mermaid
flowchart TD
    A[用户下单] --> B{选择履约方式}
    B -- 配送到家 --> C[走普通外卖派送流程]
    B -- 自提 --> D[选择自提点+自提时间段]
    D --> E{时间段单量是否已满}
    E -- 已满 --> F[提示更换时间段]
    E -- 未满 --> G[创建自提订单并支付]
    G --> H[管理端/团长接单备货]
    H --> I[生成6位自提码<br/>发送自提通知]
    I --> J[用户到店出示自提码]
    J --> K{团长/管理员核销}
    K -- 校验通过 --> L[订单=已完成<br/>记录核销时间]
    K -- 无效/已用 --> M[核销失败提示]
```

## 3. 预售采摘流程

```mermaid
flowchart TD
    A[管理端发布预售活动<br/>预售价/截止时间/发货日期] --> B[活动缓存到Redis]
    B --> C[用户浏览预售专区并下单]
    C --> D{当前时间 ≤ 截止时间<br/>且预售库存充足}
    D -- 否 --> E[下单失败: 已截止/已售罄]
    D -- 是 --> F[创建预售订单<br/>Redis预售销量+1 防超卖]
    F --> G[定时任务: 超过截止时间<br/>活动关闭]
    G --> H[到达发货日期<br/>订单批量进入备货/配送/自提流程]
```

## 4. 社区团购流程

```mermaid
flowchart TD
    A[团长发起团购<br/>商品/团购价/成团人数/截止时间] --> B[用户参团下单支付]
    B --> C[参团人数 joined+1]
    C --> D{达到成团人数?}
    D -- 是 --> E[活动=已成团<br/>订单进入统一配送至自提点]
    D -- 否 --> F{到达截止时间?}
    F -- 否 --> B
    F -- 是 --> G[活动=流团<br/>已支付订单批量退款/模拟]
    E --> H[生成自提码 → 团长核销 → 完成]
```

## 5. 临期特价 / 损耗处理流程

```mermaid
flowchart TD
    A[定时任务 每日凌晨扫描批次] --> B{距到期日天数}
    B -- ≤0 已过期 --> C[批次=过期<br/>库存作废计入损耗报表]
    B -- ≤阈值(默认2天) --> D[批次=临期<br/>按规则自动打折 如7折]
    B -- 正常 --> E[不处理]
    D --> F[用户端临期特价专区展示]
    F --> G[下单优先扣减临期批次库存<br/>降低损耗]
```

## 6. 社区帖子审核流程

```mermaid
flowchart TD
    A[用户发布帖子<br/>团购分享/好物分享] --> B[帖子=待审核]
    B --> C{管理员审核}
    C -- 通过 --> D[帖子=已通过<br/>社区列表可见, 可评论点赞]
    C -- 拒绝 --> E[帖子=已拒绝+审核意见<br/>仅本人可见]
```

| 发起团购 / 团购后台 | – | ✅ | ✅ |
| 自提码核销 | – | ✅（本自提点） | ✅ |
| 商品/分类/订单/员工/自提点/预售/报表 | – | – | ✅ |
| 帖子审核 | – | – | ✅ |
