# 后端模块划分 与 RESTful 接口文档

## 1. 工程结构

单模块 Maven 工程

```
fresh-server
├── pom.xml
└── src/main
    ├── java/com/fresh
    │   ├── FreshApplication.java            # 启动类
    │   ├── common
    │   │   ├── result/R.java                # 统一响应体
    │   │   ├── result/PageResult.java       # 分页结果
    │   │   ├── constant/StatusConstant.java # 状态常量
    │   │   ├── context/BaseContext.java     # ThreadLocal 当前登录id
    │   │   ├── exception/*Exception.java    # 业务异常
    │   │   └── enumeration/                 # 订单/商品/活动枚举
    │   ├── config
    │   │   ├── WebMvcConfiguration.java     # 拦截器注册 + Knife4j
    │   │   ├── MybatisPlusConfig.java       # 分页插件
    │   │   └── RedisConfig.java             # RedisTemplate 序列化
    │   ├── interceptor
    │   │   ├── JwtTokenUserInterceptor.java    # 用户端JWT拦截
    │   │   └── JwtTokenAdminInterceptor.java   # 管理端JWT拦截
    │   ├── properties/JwtProperties.java    # JWT配置
    │   ├── utils                            # JwtUtil / 密码 / 自提码生成
    │   ├── handler/GlobalExceptionHandler.java
    │   ├── runner/DataInitializer.java      # 初始账号保障
    │   └── modules
    │       ├── user/        # 用户登录注册、个人信息
    │       ├── address/     # 地址管理
    │       ├── category/    # 分类管理
    │       ├── product/     # 商品、批次、溯源、库存预警
    │       ├── cart/        # 购物车
    │       ├── order/       # 订单、支付、核销、评价
    │       ├── pickup/      # 自提点、自提时间段
    │       ├── presale/     # 预售活动
    │       ├── loss/        # 临期特价、损耗处理(定时任务)
    │       ├── community/   # 帖子、评论、点赞、审核
    │       ├── groupbuy/    # 团购活动、参团、成团/流团
    │       ├── notice/      # 消息通知
    │       └── admin/       # 员工管理、数据报表、文件上传
    └── resources
        ├── application.yml
        └── mapper/*.xml                      # 复杂报表 SQL
```

每个 module 包内固定分层：`controller / service(+impl) / mapper / entity / dto / vo`。
- **entity**：与表一一对应，MyBatis-Plus 注解
- **dto**：入参（提交、分页查询、审核等）
- **vo**：出参（携带冗余展示字段，如商品带分类名、订单带明细列表）

## 2. 统一约定

- 响应体：`R<T> { code, msg, data }`，code=1 成功，0 失败
- 分页：入参 `page/pageSize`，返回 `PageResult { total, records }`
- 鉴权：请求头 `Authorization: Bearer {token}`；用户端 token 载荷含 userId，管理端含 empId
- 接口前缀：用户端 `/user/**`，管理端 `/admin/**`

## 4. 定时任务
| 任务 | 频率 | 说明 |
|---|---|---|
| OrderTimeoutTask | 每分钟 | 超时未支付订单自动取消并回滚库存 |
| BatchExpiryTask | 每日 00:30 | 批次临期标记/自动打折/过期作废，刷新临期特价缓存 |
| PresaleCloseTask | 每 5 分钟 | 预售到点关闭 |
| GroupBuySettleTask | 每 5 分钟 | 团购到期结算：成团→流转配送；未满→流团退款 |
