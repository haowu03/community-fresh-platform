# 社区便民生鲜配送平台 — 需求文档

> 版本：v1.0　　

---

## 1. 项目概述

### 1.1 项目背景
面向社区场景的生鲜（蔬菜、水果、肉禽、水产）电商平台，解决社区生鲜"最后一公里"问题。相比普通外卖，生鲜具有**保质期短、冷链要求、按重量计价、损耗高、产地溯源**等业务特性，并衍生出**社区自提、预售采摘、临期特价、社区团购**等差异化玩法。

### 1.2 项目定位
- 前后端分离架构：后端 Java + SpringBoot 3 + MyBatis-Plus + MySQL + Redis；前端 Vue3 + Element Plus（管理端）/ Vue3 + Vant（用户端 H5，按需开发）。
- 经典电商系统分层风格（Controller / Service / Mapper），包含用户端 / 管理端完整业务闭环。

### 1.3 系统角色

| 角色 | 端 | 说明 |
|---|---|---|
| 普通用户 USER | 用户端 | 浏览、购物车、下单（配送/自提）、支付、评价、发帖、参团 |
| 团长 LEADER | 用户端（含团长后台页） | 具备普通用户全部能力；绑定自提点；发起团购、管理团购订单、自提码核销 |
| 平台管理员 ADMIN | 管理端 | 商品/分类/订单/员工/自提点/预售/临期/帖子审核/数据报表 |

> 用户表 `role` 字段区分 USER / LEADER；管理员使用独立的 `employee` 表登录管理端。

## 2. 功能需求

### 2.1 保留的基础功能

**用户端（C 端）**
1. 登录 / 注册（账号密码 + JWT）
2. 商品浏览：分类导航、商品列表、商品详情、商品搜索
3. 购物车：添加（支持按份 / 按重量）、修改、删除、清空
4. 下单：地址选择、自提点选择、订单提交、模拟支付
5. 订单管理：历史订单、订单详情、取消订单、再来一单、催单
6. 地址管理：增删改查、默认地址
7. 评价：订单完成后对商品评分、文字评价

**管理端（B 端）**
1. 商品管理：商品 CRUD、起售停售、图片上传
2. 分类管理：分类 CRUD、排序、启用禁用
3. 订单管理：订单搜索、接单、拒单、派送、完成、取消
4. 员工管理：员工 CRUD、启用禁用、修改密码
5. 数据报表：营业额、用户、订单、销量排名统计

### 2.2 生鲜差异化特色功能（新增，重点）

#### 2.2.1 生鲜商品特性
- **保鲜类型**：常温 / 冷藏 / 冷冻（`product.fresh_type`），商品卡片与详情展示冷链标识
- **保质期管理**：商品设置保质期天数；按**批次**（`product_batch`）管理生产日期、到期日期、批次库存
- **库存预警**：商品设置预警库存，库存 ≤ 预警值时进入管理端预警列表
- **商品溯源**：产地、种植户、采摘日期、检测报告、运输信息（`product_trace`），用户端详情可查看
- **按重量计价**：商品支持"按份"与"按重量（斤/千克）"两种计价方式；按重量商品在购物车 / 订单中记录实际称重重量，金额 = 单价 × 重量

#### 2.2.2 社区自提点
- 后台维护多个自提点（名称、地址、经纬度、绑定团长、营业时间）
- 每个自提点维护**自提时间段**（如 09:00–12:00、14:00–18:00，限制单量）
- 用户下单二选一：**配送到家**（选地址）/ **社区自提点自提**（选自提点 + 时间段）
- 自提订单备货完成后生成**自提码**（6 位数字），推送通知（消息记录模拟）
- 团长 / 管理员凭自提码**核销**，订单流转为已完成

#### 2.2.3 预售采摘模式
- 管理端发布预售活动：预售商品、预售价、限购库存、**下单截止时间**、**统一发货日期**
- 用户在截止前下单支付；截止后活动关闭，汇总订单按发货日期集中配送 / 自提
- Redis 缓存预售活动与销量，防止超卖

#### 2.2.4 损耗处理（临期特价）
- 定时任务每日扫描批次：距到期日 ≤ 阈值（默认 2 天）自动标记"临期"并按规则打折（如 7 折）；过期批次自动下架作废
- 用户端"**临期特价专区**"：展示临期折扣商品，单独入口
- 管理端损耗报表：统计临期 / 过期作废批次数量与金额

#### 2.2.5 社区板块
- 用户发布帖子：团购分享 / 好物分享两类，图文
- 评论、点赞（防重复点赞）
- 管理员审核：待审核 / 通过 / 拒绝（附审核意见），未通过不在列表展示

#### 2.2.6 批量采购团购
- 团长发起团购：选择商品、设置**团购价**、成团人数、起止时间、关联自提点
- 用户参团下单支付；达到成团人数 → 成团（状态流转，统一配送到自提点）
- 截止时间未满团 → 自动流团，已支付订单原路退款（模拟）
- 团长后台：我的团购、成团情况、参团成员、核销

## 3. 非功能需求

| 项 | 要求 |
|---|---|
| 架构 | 前后端分离，RESTful 接口，统一响应体 `R<T>` |
| 安全 | JWT 双体系（用户端 / 管理端），BCrypt 密码加密，接口拦截器鉴权 |
| 性能 | Redis 缓存：首页商品列表、分类、商品详情、库存、预售活动；缓存与 DB 双写一致性 |
| 事务 | 下单扣库存、参团、成团 / 流团、核销等核心链路本地事务保证 |
| 防重 | 订单提交幂等（防重复提交）、点赞唯一约束、库存乐观扣减防超卖 |
| 可维护 | controller / service / mapper / entity / dto / vo 分层，Knife4j 接口文档，注释规范 |

## 4. 技术选型

| 层 | 技术 |
|---|---|
| 框架 | SpringBoot 3.2、SpringMVC、MyBatis-Plus 3.5、Spring AOP / 定时任务 |
| 存储 | MySQL 8、Redis 7（缓存 / 简单分布式锁） |
| 工具 | Lombok、Knife4j（OpenAPI3）、Hutool、Fastjson2、JWT（jjwt）、BCrypt |
| 前端 | Vue3 + Element Plus（管理端）、Vue3 + Vant（用户端 H5） |
| 部署 | Jar 直接运行，IDEA 导入即可开发 |

## 5. 约束与简化说明
1. 支付为**模拟支付**（回调直接置为已支付），预留微信 / 支付宝对接位。
2. 消息通知（自提通知、成团通知）以数据库消息记录模拟，预留短信 / 订阅消息位。
3. 文件上传提供本地存储实现，可平滑替换 OSS。
